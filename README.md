**Project Title: AI-Powered Resume Screening and Candidate–Job Matching Using NLP and AutoML**

Developed an intelligent resume screening system that predicts candidate–job compatibility using advanced Natural Language Processing (NLP), deep learning-based text representations, and Automated Machine Learning (AutoML).

The system integrates **Word2Vec, FastText, and pretrained RoBERTa embeddings** to extract meaningful representations from candidate resumes and job descriptions. It combines semantic similarity scores with candidate experience and job experience requirements to generate features for an AutoGluon regression model.

**Key Features:**

* Resume and job description preprocessing.
* Word2Vec and FastText word embeddings.
* Contextual text representations using RoBERTa.
* Candidate–job semantic similarity calculation.
* AutoGluon regression for matched-score prediction.
* Automated candidate ranking based on predicted compatibility scores.
* Model evaluation using R², Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE).
* Actual-versus-predicted visualization and residual analysis.

**Tech Stack:** Python, Pandas, NumPy, PyTorch, Gensim, Hugging Face Transformers, Scikit-learn, AutoGluon, Matplotlib, and Seaborn.

**Objective:** To improve the efficiency of preliminary resume screening by combining semantic understanding and automated predictive modelling.

**Environment:** Google Colab with optional GPU acceleration.
